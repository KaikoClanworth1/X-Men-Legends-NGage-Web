# e11m11 — Mansion grounds (exterior), Episode 11

- Factory 0x1007efbc (new 0xF0), ctor 0x1007ef84, vtable 0x1011d5f4 (dtor 0x1007efac, Init 0x1007efe4, OnStart 0x1007fc20, OnLoaded 0x1007fde4)
- Map: `map11_man_out.btm`
- Dialogue: `e11m04.dlg`, slot 0
- Sound banks: `mansion_ext.swb`, `errie_bank_1.swb`
- Episode table: idx 11 (Magma/Storm/Phoenix/Iceman) and idx 12 (Phoenix + 3 free). The script has two visits: the first is the "…" prologue and the second is the GRSO hunt. **Which visit it is comes from `GetVarC0()==2`** (see Unknowns).

## State fields (all save vars, all set to 0 in Init)
| field | meaning |
|---|---|
| fc8 | mode: 0 = prologue not done, 1 = prologue done and doors lead to e11m03, 2 = GRSO hunt |
| fcc | step counter for the prologue cinematic (0x1007ff04) |
| fd0 | GRSO kill count (0..30). More than 29 means all are dead and the doors are enabled |
| fd4, fd8, fdc, fe0, fe4, fe8, fec | one-shot flags for trigger groups spawn1..spawn7 |

## Init (0x1007efe4)
- ReserveHandlers(59) and ReserveSaveVars(10). All fields above are set to 0.
- `LoadDialogueFile("e11m04",0)`, `LoadSoundBank("mansion_ext.swb")`, `LoadSoundBank("errie_bank_1.swb")`
- Loot for `grsosldr`: concussion bomb 5%, large med pack 10%, medium med pack 15%
- `SetCharTypeLevel("grsosldr", 15, refill=1)`
- `Script::SetVarBC(?)` (the value is UNKNOWN because the register was lost)
- No timers.

## Flow summary
- **First visit (fc8 goes 0 to 1):** Alison's "diary" monologue plays. Fade out, the party is placed near the mansion, fade in, and control returns. Beast's "calltoarms" plays, then objective 61 "…" is added. Any door ("…") calls `ChangeLevel("e11m03", 1)`.
- **Second visit (VarC0==2, fc8 becomes 2):** objective 20 "…" is added and Jean's "missionstart" plays. Seven trigger groups teleport 30 GRSO soldiers (level 15) to the party, each with a Jean one-liner. Each kill shows a remaining-count popup, and character24 drops a Flare Gem. The 30th kill plays "missionend", completes objective 20 and adds objective 62. Any door ("…") then fades out, calls SetObjective(62,0,1) and `CompleteEpisode(2)`, which loads e11m05 at spawn2 (table idx 13).
- No hero unlocks, no movies and no timers.

## Unknowns
- UNKNOWN: who sets VarC0=2 before the hunt visit (probably e11m03/e11m05 or the episode loader). Side effect: if a save restores fc8=1 (prologue done), OnStart takes the hunt branch and step() sets fc8=2, so the hunt starts instead of the e11m03 door (0x1007fc44, 0x100801a0).
- UNKNOWN: OnStart's fc8==0 branch passes slot r4=0 to all 4 GetPartyMemberId calls (lift 0x1007fc88..0x1007fce0). OnLoaded uses slots 0..3. This looks like a compiler/source bug.
- UNKNOWN: `SetObjective(62, 0, 1)` at 0x100803e0 uses state 0, not 2. The meaning of state 0 is not confirmed.
- UNKNOWN: the SetVarBC value in Init and the SpawnEntity dir argument for the Flare Gem.
- Tool note: pseudo.py shows the kill switch on the post-increment fd0. The lift at 0x1008042c..0x1008043c switches on the pre-increment value. The jump table at 0x10080444 maps case0 to 0x100804bc (popup 88) and case29 to 0x1008068c (missionend).
