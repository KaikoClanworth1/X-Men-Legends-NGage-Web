  MapSet4(33, 25); MapSet4(34, 25);           // UNKNOWN: tile op meaning

introStep() { switch (this.fdc) {            // 0x1007a510; next = 0x1007a6d8 (fdc++; introStep)
  case 0: SetPlayerControl(0); CameraPanTo(475, 3575, 0x1000);
          FaceEntity("moira","colossus"); FaceEntity("colossus","moira"); SetFacing("forge", 4);

npcHandler(evt) { switch (evt.code) {
  case 0: SetActionPromptId(evt.subject.id, 1); break;
  case 3: SetActionPromptId(evt.subject.id, 0);

  case 2: FaceEntity(NAME, subject); FaceEntity(subject, NAME);

            else StartDialogue(LEADER_LATER, this, null, 0);
          } else {

            StartDialogue(GENERIC, this, null, 1);   // 3-line generic chat with "…"
          }

  case 5: /* colossus only (jumptable 0x1007a70c) */ if (fe8 == 3) exitNext(); break;

## 6. Flow summary

1. First entry: Colossus unlocked (hero 1); objective 19 "…" added; 4 NPCs set to ally; intro scene (Moira and Colossus about Illyana's Legacy Virus); objective 19 completed.
2. Optional: talk to Moira, Colossus, Multiple Man and Forge. The leader gets Magma chats from mission10, other party members get generic lines. Once the leader has talked to all four, walking away from any of them plays "GoHome" once.
3. Optional Forge crafting: needs Case + Power Supply + at least one of Elemental Gem / Energy Gem / Shield Motivator. Forge builds one item (Elemental Shield / Energy Supplier / Shield Generator). The parts are not removed. It only happens once: ff8=1 after any outcome, including "wait" or not enough parts.
4. `seecyclops1/2` zones: Cyclops/Havok call scene, then Cyclops walks to (4150,3350).
5. `timeToLeave`/`TimeToLeave2` zone (reachable any time): exit scene, party HP set to 1500, `SetNextMovie("mv_02")`, `CompleteEpisode(1)` → idx 11 `e11m11` at spawn1.
- Heroes unlocked: Colossus (1). No combat and no win condition other than the exit zone.

## 7. Unknowns

- UNKNOWN: purpose of MapSet4(33,25)/(34,25) and MapSet1(85,35,1) in OnStart.
- UNKNOWN: SetCinematicMode looks reversed compared with API.md. It is called with `(0,0)` when a scene starts (0x1007ae40, 0x1007b11c) and with `(1,0)` when it ends (cycStep case 5, 0x1007b00c). So 1 may mean normal gameplay and 0 cinematic.
- UNKNOWN: label case. generic.dlg labels are `Colossus`/`Forge`/`Moira`/`Multiple Man`, but the script passes lowercase names (0x1007a880, 0x1007aa5c, 0x1007abf0, 0x1007ad84). The lookup is probably case-insensitive.
- UNKNOWN: SetHealthId(…,1500) may set exact HP or be clamped to max.
- Movie literal is "mv_02" at episode 10, which may be a prototype placeholder.
- The Moira-N / MMan-N labels are never used (the else branch still loads "-1").
