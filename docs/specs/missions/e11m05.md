## State fields
| field | saved | meaning |
|---|---|---|
| fc8 | yes | visit phase: 0 = not set up yet, 1 = first visit (briefing, then leave), 2 = return visit (debrief) |
| fcc | yes | 1 = mission briefing in the War Room already played |
| fd0 | yes | debrief cinematic step counter (0..5) |
| fd4 | no | containers looted this session (max 3 items) |
| VarBC | - | set to 6 in Init (UNKNOWN meaning) |
| VarC0 | - | read in onFadedIn; ==2 means "…" (set by another mission, UNKNOWN which) |

## Flow summary
1. **First visit (fc8=1)**: Toad is set neutral and tiles (10,23..25) are changed. Objective 61 "…" should already be active (added by an earlier mission). Entering `warroom` plays `missionbriefing`, which adds objective 20 "…" and completes 61. Before the briefing the elevators pop "…"; after it they show "…", and the action button fades out and calls CompleteEpisode(2).
2. **Return visit (VarC0==2, fc8=2)**: objective 62 "…" is added. Entering `warroom` plays debriefs 1-3 (GRSO beacon traced to Canada, the Weapon X facility), completes 62, then ChangeLevel("e11m03", 2). The elevators show "…", but pressing action only pops "…".
- No heroes unlocked, no movies set. Containers give at most 3 random consumables per load.
