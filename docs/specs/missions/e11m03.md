# e11m03 — Xavier Mansion hub (interior free roam) + "…" ending cutscene

## 1. Header
- Factory `0x1007b970` (new 0xE4), ctor `0x1007b938`, vtable `0x1011d5c4`
  - [2] dtor `0x1007b960`, [3] Init `0x1007b998`, [4] OnStart `0x1007c9e8`, [5] OnLoaded `0x1007cb8c`
- Map: `map03_man_1.btm` (79 records)
- Dialogue: slot 0 = `e11m04.dlg`, slot 1 = `generic.dlg`, slot 2 = `books.dlg`
- Sound banks: `wood_doors.swb`, `space_doors.swb`, `errie_bank_1.swb`, `man_int_amb.swb`
- Not in the episode table (§3). Exits with `ChangeLevel("e11m05",1)`, or in the VarC0==2 cutscene variant `CompleteEpisode(1)`.
- No objectives, no timers, no loot tables.

## 2. State fields
| field | save | meaning |
|---|---|---|
| fc8 | yes | FadeIn-callback mode: 0 = normal first entry (do setup), 1 = cutscene (advance fe0) |
| fcc | yes | Rogue/Gambit scene step (0 none, 1 after "meetrogue", 2 after Gambit's first walk) |
| fd0 | yes | 1 = "…" group move already started (guard in 0x1007d430) |
| fd4 | yes | count of finished conversations using cb 0x1007d228; at 3 the level exits |
| fd8 | yes | 1 = met Nightcrawler |
| fe0 | yes | Cyclops/Xavier cutscene step counter |
| fdc | no | items handed out from containers (gives only while fdc <= 8) |

## 3. Init (0x1007b998)
- ReserveHandlers(0x46); register handlers (table below).
- SetZoneTriggerLimit("container1..19", 1, 1); SetFlag400("student1..9", 1).
- Save vars: fd8, fcc, fc8, fd0, fd4, fe0. All state fields incl. fdc = 0.
- LoadDialogueFile("e11m04",0), ("generic",1), 4 sound banks, ("books",2).
- `if (GetVarC0()==1) SetVarBC(4); else if (GetVarC0()==2) SetVarBC(5);` (lift 0x1007c98c–c9d8).

## 5. Pseudocode
```js
OnStart() {                                   // 0x1007c9e8
  for (s=0..3) SetActionPromptId(GetPartyMemberId(s), 1);
  SetCinematicMode(0,0);
  if (GetVarC0() == 2) {                      // ending-cutscene entry
    this.fc8 = 1;
    for (s of [1,2,3]) TeleportId(GetPartyMemberId(s), 50, 50, 0); // park other party members off-map
    SetHudVisible(0); SetPlayerControl(0);
    Teleport("xavier", 0x1a77, 0x117b, 4);      // (6775,4475)
    CameraPanTo(0x19c8, 0x10fe, 0x1000);        // (6600,4350) instant
  }
  FadeIn(this, onFadeIn);
}
OnLoaded() { FadeIn(null); SetCinematicMode(0,0); for (s=0..3) SetActionPromptId(GetPartyMemberId(s),1); }

onFadeIn() {                                  // 0x1007cc20
  if (this.fc8 == 0) {
    this.fc8 = 1;
    MapSet1(8, 55, 1); MapSet1(8, 44, 1);     // UNKNOWN effect
    for (s=0..3) SetActionPromptId(GetPartyMemberId(s), 1);
    FaceEntity("rogue","gambit"); FaceEntity("gambit","rogue");
  } else if (this.fc8 == 1) cutNext();        // 0x1007d6c4
}

// --- NPC talk ---
nightcrawler(evt) {                           // 0x1007cd1c
  if (evt.code==0) SetActionPromptId(id(evt.subject),1);
  else if (evt.code==3) SetActionPromptId(id(evt.subject),0);
  else if (evt.code==2) {
    FaceEntityNameId("nightcrawler", id(evt.subject)); FaceEntityIdName(id(evt.subject), "nightcrawler");
    SetDialogueSpeakerEntity(evt.subject);
    if (id(evt.subject) == GetPartyMemberId(0)) {
      if (this.fd8 == 0) { StartDialogue("meetnightcrawler", this, convDone, 0); this.fd8 = 1; }
        // helping Cyclops find how Mystique knew about HAARP; someone in the military leaks to the Brotherhood
      else StartDialogue("metnightcrawler", this, null, 0);   // literal @0x100fc47c; "…" -> options2
    } else StartDialogue("nightcrawler", this, convDone, 1);   // generic: "…"
  }
}
colossus(evt) {                               // 0x1007cea8
  0/3: action prompt on/off;
  2: face each other;
     if (subject is leader) StartDialogue("meetcolossus", this, convDone, 0); // sister Illyana's illness
     else { SetDialogueSpeakerEntity(evt.subject); StartDialogue("colossus", this, convDone, 1); } // generic "…"
}

// --- Rogue / Gambit scene ---
rogue(evt) {                                  // 0x1007cffc (also zone "meetrogue")
  if (id(evt.subject) != GetPartyMemberId(0)) return;
  if (evt.code==0 && this.fcc==0 && this.fd0==0) rogueStep();
  if (evt.code==2) StartDialogue("meetrogueoptions", this, convDone, 0); // Rogue on Gambit & Magneto
}
rogueStep() {                                 // 0x1007d0ac
  switch (this.fcc) {
    case 0: StartDialogue("meetrogue", this, rogueDlgDone, 0); break; // Gambit asks Rogue about Magneto; Alison interrupts; Gambit leaves
    case 1: WalkToTile("gambit", 27, 76, -1); break;
    case 2: StartDialogue("meetrogueoptions", this, convDone, 0); WalkToTile("gambit", 23, 46, -1); break;
  }
}
rogueDlgDone(r) { this.fcc++; rogueStep(); }  // 0x1007d218
gambit(evt) {                                 // 0x1007d1ac
  if (name(evt.subject)=="gambit" && evt.code==5 && this.fcc==1 && this.fd0==0) { this.fcc=2; rogueStep(); }
}

convDone(r) {                                 // 0x1007d228
  this.fd4++;
  if (this.fd4 == 3) { this.fd4 = 4; leaveMansion(); }
}

// --- exits ---
door(evt) {                                   // 0x1007d248
  0: SetActionPromptId(id(subj),1); ShowMessage(5,1);   // "…"
  3: SetActionPromptId(id(subj),0); ShowMessage(5,0);
  2: leaveMansion();
}
leaveMansion() {                              // 0x1007d430
  if (this.fd0) return; this.fd0 = 1;
  WalkToTile("gambit",32,49,-1); WalkToTile("colossus",31,49,-1);
  WalkToTile("rogue",32,48,-1);  WalkToTile("nightcrawler",31,48,-1);
  gotoE11m05();                               // called immediately, no wait/fade
}
elevator(evt) {                               // 0x1007d2e0
  0: prompt on; ShowMessage(6,1);             // "…"
  3: prompt off; ShowMessage(6,0);
  2: FadeOut(this, gotoE11m05);
}
gotoE11m05() {                                // 0x1007d39c
  for (s=0..3) SetActionPromptId(GetPartyMemberId(s), 0);
  ChangeLevel("e11m05", 1);
}

// --- Cyclops leaves (VarC0==2 entry) ---
cutNext() { this.fe0++; cutStep(); }          // 0x1007d6c4 (0x1007d6d4 = tail to it, dialogue cb)
cyclops(evt) { if (name(evt.subject)=="cyclops" && evt.code==5) cutNext(); } // 0x1007d6d8
cutStep() {                                   // 0x1007d4dc, switch(fe0-1), jt 0x1007d4fc
  case 1: Teleport("cyclops", 0x1806, 0x109a, 0);           // (6150,4250)
          FaceEntity("xavier","cyclops");
          WalkToTile("cyclops", 66, 44, DirectionTo(0x19fa,0x1162, 0x1a77,0x117b)); // end facing Xavier
          break;                                            // walk end -> cyclops handler -> step 2
  case 2: StartDialogue("cyclopsleavingxavier", this, cutNext, 0); break;
          // Cyclops tells Xavier he's leaving to meet Alex in Canada (Brotherhood info); Xavier: take the X-Men
  case 3: WalkToTile("cyclops", 73, 48, -1); FadeOut(this, cutNext); break;
  case 4: SetHudVisible(1); SetPlayerControl(1);
          for (s=0..3) SetActionPromptId(GetPartyMemberId(s),0);
          CompleteEpisode(1); break;
}

// --- flavour ---
student(evt) {                                // 0x1007d724
  0/3: prompt on/off;

     StartDialogue("Student-11-" + r, this, null, 1);        // generic.dlg Student-11-0..9

bookcase(evt) {                               // 0x1007d9cc
  0/3: prompt on/off;
  2: r = rand() % 15; SetDialogueSpeakerEntity(evt.subject);
     StartDialogue("Book-" + (r+1), this, null, 2);          // books.dlg Book-1..15
}
container(evt) {                              // 0x1007dce0
  0: prompt on; ShowMessage(158,1);           // "Search"
  3: prompt off; ShowMessage(158,0);
  2: ClearMessages();
     item = null;
     if (this.fdc <= 8) {
       r = rand() % 100;
       item = r>96 ? "…" : r>91 ? "…" : r>81 ? "…" : r>66 ? "…" : null;
     }
     if (item) { GiveItem(item); this.fdc++; } else ShowPopupText(159);   // "Empty"
     RemoveEntity(name(evt.other));           // one search per container
}
```

## 6. Flow summary
- Normal entry (VarC0 != 2): free roam. Leader approaching Rogue/meetrogue plays the Gambit/Rogue scene (Gambit walks to tile (27,76), then (23,46) while Rogue's options open).
- Talkable: Nightcrawler, Colossus, Rogue; students/bookcases flavour; containers give random consumables (max 9).
- Exit: elevator1..4 → FadeOut → `ChangeLevel("e11m05",1)`; door1..6, or the 3rd conversation ending via `convDone` → Gambit/Colossus/Rogue/Nightcrawler walk to tiles (31..32,48..49) and `ChangeLevel("e11m05",1)` immediately.
- Cutscene entry (VarC0 == 2, SetVarBC(5)): party 1–3 parked, Cyclops walks to Xavier, "cyclopsleavingxavier", Cyclops walks off, fade → `CompleteEpisode(1)` (next table entry; presumably idx 14 e12m18, Cyclops+Wolverine forced). No movie set here.
- No objectives, no heroes unlocked, no quest XP.
